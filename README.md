# Pippy

I built Pippy as a small, friendly reminder to take care of yourself while you work.

Rally nudges you to move, Blink guides a 20-second eye break, and Mochi reminds you to stretch. Each buddy has soft artwork and gentle animation, with snooze controls and optional sound. Blink chimes at the start, halfway through, and when the break is done.

## Install

Download the latest `Pippy-0.4-arm64.pkg` from [Releases](https://github.com/0xcrvpto/pippy/releases), quit any running copy of Pippy, and open the installer. It installs **Pippy.app** in **Applications**.

Requires an Apple silicon Mac and macOS 13 or later. This release is not Developer ID signed or notarized, so macOS may show an unverified-developer warning. It is an early personal build.

## Use

Open Pippy from Applications. Adjust reminders and sound in Preferences, or preview each buddy from the menu-bar menu. Closing the window keeps reminders running; choose **Quit Pippy** to stop them.

Eye and stretch reminders run from 11 a.m. to 11 p.m.; workout reminders run between 2 and 6 p.m. Snoozes last for the current app session. macOS Reduce Motion disables mascot movement.

The app stores settings locally and does not require an account or network connection.
